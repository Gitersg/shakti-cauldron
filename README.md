# Shakti Cauldron

Local-first chemistry mastery desk by [Shrinjoy Ghosh](https://github.com/Gitersg).

Open `index.html` in any browser. There is no install, no account, and no server. Missions, ranks, alchemy notes, and settings stay in that browser until you export a backup.

The hosted desk carries the longer guided path. This file carries a starter set you can extend. Both speak the same backup JSON (`app: "shakti-cauldron"`, `version: 1`). Export on one, import on the other.

## What it trains

- Guided missions: read, solve, safe practicals, and product-planning cards.
- Your own missions, tracks, XP rewards, and rank titles.
- An alchemy notebook: target product, ingredients, conditions, method, hazards, observations, and any extra fields you add.
- Experience that levels a 20-rank curve. Higher ranks cost more XP. Rank *n* starts at `40 × (n − 1)^1.9` XP, rounded.
- Export and import of the whole desk.

## What it will not do

Shakti Cauldron does not publish home recipes for hazardous concentrates, drugs, or explosives. The phenyl mission is a product specification and a refusal list for a pine-oil disinfectant emulsion. It is not a mix sheet. Real bench work belongs in a supervised lab, with a source you trust, and within the law where you live.

See [SAFETY.md](SAFETY.md).

## Use it

1. Download [index.html](index.html), or use **Download portable app** inside the hosted desk.
2. Open the file. Double-click is enough.
3. Work a mission. Check every step. Seal it. XP lands once.
4. Export a JSON backup before you clear the browser.
